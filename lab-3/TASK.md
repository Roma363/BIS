# Лаб. Робота №3
## Розробка програми генерації ключів шифрування за схемою RSA та реалізація процедури шифрування за схемою RSA

Програма повинна реалізувати схему розрахунку ключів шифрування за алгоритмом RSA, сформувати відкриті та закриті (секретні) ключі шифрування. Далі програма має реалізувати режими шифрування та розшифрування файлів із перевіркою достовірності результатів.

Потрібно сформувати вихідний файл із текстом, далі Програма формує зашифрований файл. Після цього Програма повинна забезпечити можливість розшифрування файлу, який повинен збігтися з вихідним.

В процесі роботи Програми необхідно запросити введення з клавіатури довжини бази ключа шифрування, далі вивести ключ на екран (у RSA він складається з двох частин –  відкрита  і закрита частини). Далі Програма запитує ім'я файлу для шифрування та ім'я файлу для запису зашифрованої інформації.
