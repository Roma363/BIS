# Lab 2 — генератор великих простих чисел і RSA

Програма генерує прості числа з кількома десятками десяткових цифр і створює пару ключів RSA.

Реалізовано:

- генерацію випадкових кандидатів заданої довжини;
- обов'язкову перевірку кандидатів за малою теоремою Ферма;
- додаткову перевірку тестом Рабіна—Міллера;
- пошук оберненого елемента розширеним алгоритмом Евкліда;
- створення відкритого та закритого ключів RSA;
- демонстрацію шифрування і розшифрування повідомлення.

Для великих чисел використовується стандартний тип `math/big`, оскільки він підтримує арифметику без обмеження розміру цілого числа. Кандидати генеруються криптографічно стійким генератором `crypto/rand`.

## Запуск

```powershell
go run .
```

Кількість цифр простих чисел і кількість раундів перевірки задаються константами `primeDigits` і `testRounds` у `main.go`.
