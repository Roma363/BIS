# Лаб. Робота №2 
Розробка програми генератора великих простих чисел (BПЧ) для шифрування та обчислення ключів за схемою RSA для  чисел з декількома десятками десяткових знаків. Для створення таких простих чисел можна використовувати формули відповідно до тесту Рабіна чи інші методи, але для перевірки властивостей сформованих кандидатів в прості числа необхідно використовувати малу теорему Ферма.
