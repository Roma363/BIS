# Lab 3 — RSA

Програма генерує пару ключів RSA, шифрує файл відкритим ключем і розшифровує його закритим ключем.

Реалізовано:

- введення з клавіатури кількості десяткових цифр у простих числах `p` і `q`;
- генерацію випадкових великих простих чисел тестом Міллера–Рабіна;
- обчислення модуля `n = p * q` і функції Ейлера `phi = (p - 1) * (q - 1)`;
- пошук відкритого показника `e = 65537` та оберненого показника `d`;
- виведення відкритої та закритої частин ключа на екран;
- шифрування кожного байта вихідного файла;
- використання ключів, згенерованих у пам'яті;
- розшифрування зашифрованого файла;
- побайтове порівняння початкового та відновленого файлів.

Арифметика великих чисел реалізована стандартним пакетом `math/big`. Для шифрування та розшифрування дані зберігаються у текстовому форматі `RSA_FILE_V1`.

## Структура проекту

- `main.go` — консольний інтерфейс і повний цикл роботи програми;
- `rsa.go` — генерація простих чисел та ключів RSA через `math/big`;
- `file.go` — читання, запис і перевірка зашифрованих і відновлених файлів.

## Запуск

У інтерактивному режимі:

```powershell
go run .
```

Програма запитає довжину простих чисел у десяткових цифрах, імена вихідного, зашифрованого та відновленого файлів.
